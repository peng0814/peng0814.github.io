把 d 轨道转起来：三个能自己动手的 3D 演示

Created2026-11-24|Updated2026-11-24
|Post Views:

结构化学里讲 d 轨道，最难受的是纸上那几张图：五个形状长得差不多，方向却各不相同，老师一句”这个沿 xy 平面、那个沿对角线”，全靠脑子转。可脑子转三维，转不过电脑。

所以我做了三个能直接上手转的演示。它们不是画出来的示意图，而是每一帧都按球谐函数现算的等值面——五个轨道、波函数的正负相位、σ/π/δ 三种重叠，都是算出来的。

一、五个 d 轨道，想看哪个点哪个

红蓝是波函数的正负相位（ψ > 0 / ψ < 0），不是”电子多”和”电子少”。相邻的瓣正负交替，这一点在讲成键的时候特别关键。

最有用的是可以自由勾选叠加：点 d_xy 再点 d_x²−y²，两个轨道就叠在同一个空间里，45° 的取向差一眼就看出来了。

还有个细节值得玩一下：把五个轨道全部叠上，会变成一团彩球。这不是渲染出错——五个 d 轨道填满时 Σ|ψ|² 与方向无关，本来就接近球形，这也正是”全充满的 d 亚层是球对称”的来由。

👉 打开演示：五个 d 轨道

二、面对面成键：δ 键

两个 d_xy 平行靠近，四对同号瓣正面对上，接成四根贯穿两个原子核的”桥”——这就是 δ 键。它的标志是沿键轴有两个节面（xz 和 yz 平面），这也是 δ 和 σ、π 的分界。

页面里可以拖键长、拖轨道尺度，右上角实时给出重叠积分 S。换成”反键”组合，键中点会多出一个节面，相位在中间翻一次——这个对比比任何静态图都直观。

👉 打开演示：δ 键

三、σ / π / δ 三种重叠，带时间轴

下面这个可以直接在文章里玩（建议用电脑、用 Edge 或 Chrome 打开）：

五个轨道全部可选，亮点是底部那条可拖动的时间轴：核间距从 20 a₀ 一路收到 5 a₀，你能亲眼看见两个轨道从各自独立，到波瓣开始交叠，最后接合成键的全过程。

拖动时注意看三个面板的差别——d_z² 是头对头（σ），d_xz 是肩并肩（π），d_xy 是面对面（δ）。同样的距离下，它们的重叠区形状完全不一样。

👉 打开全屏版：σ / π / δ

如果你想要一张能贴进作业的图，每个页面右下角都有「保存 PNG」，导出的就是当前视角的高清图。

一点技术说明

  • 用的是氢原子 3d 实轨道：径向部分 ∝ r²e^(−r/3)，角向是实球谐函数；等值面取 |ψ| 为定值。
  • 全部实时计算：WebGL2 片元着色器里做光线步进，逐像素求 |ψ| = c 的交点，法线取梯度。所以转起来不糊、放大也不失真。
  • 页面是三个独立的 HTML，不联网、不装插件，双击就能开。
  • 需要浏览器支持 WebGL2。手机上部分浏览器和微信内置浏览器不支持，会黑屏，用电脑看比较稳。

写这个东西最大的收获是：“看懂了”和”能转着看”完全是两回事。以前背”d_xy 在 xy 平面内、沿 45° 对角线”，现在是转过一遍之后，闭眼也能想出它长什么样。

希望对你也有用。
